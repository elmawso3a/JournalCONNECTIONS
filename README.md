# Journal 2 Connections

موقع مذاكرة تفاعلي ثنائي اللغة (عربي / English) بيربط الـ 26 LO في Journal 2 (KFS Capstone Club) بخمس أفعال: يحمي ويعزل، يختار الخامة، يشكّل ويثبّت، يقيس ويختبر، يوثّق ويعرض.

An interactive bilingual study site that links the 26 learning outcomes of Journal 2 (KFS Capstone Club) through five verbs.

## Features / المميزات

- **Barrier Lab / معمل الحاجز**: live canvas simulation of heat, light or water passing through a layered barrier, with a measured pass-through rate.
- **Map / الخريطة**: all 26 LOs in four parts each (Concept, Link, Example, But), grouped by the five verbs.
- **Quiz me / اختبرني**: spaced flashcards and an example-to-LO quiz, with streaks and keyboard shortcuts.
- **Numbers / الأرقام**: 11 calculations from the journal with fresh numbers every time.
- **Search / بحث**: press `/` or `Ctrl+K` to search every LO in Arabic or English.
- Language switch (AR / EN / AR+EN), light and dark themes, rank system, progress saved in the browser.

## Run / التشغيل

It is a single static file. Open `index.html` in a browser, or serve the repo with GitHub Pages.
